# تُراث — منصة معرفة إسلامية مترابطة

**الموقع الحيّ:** https://ghassanmazen00.github.io/turath/ (يُبنى ويُنشَر تلقائيًا عند كل دفع إلى `main`)

القيمة في **طبقة الربط** بين المصادر لا في امتلاك النصوص.
قرارات المشروع وقواعده الحمراء في [`CLAUDE.md`](./CLAUDE.md) — اقرأه أولًا.

## الحالة

النموذج الرأسي الأول يعمل من طرف إلى طرف: صفحة آية واحدة تسحب فعليًا
نصّ الآية + تفسيرين + الأحاديث المرتبطة + موضع أحكامها.

```
python3 -m turath.server            # http://127.0.0.1:8000/  — الرئيسية
python3 -m unittest discover -s tests
```

الآيات تُبنى **عند الطلب**: افتح أي آية فيجلبها الخادم من المصادر ويخزّنها،
فالمصحف كله متصفَّح دون تحميل ٦٢٣٦ آية مسبقًا. أول طلب يُحمّل فهرس الحديث
(نحو ٨ ثوانٍ) ثم كل آية تُبنى في ثانية أو ثانيتين وتُخزَّن.

المسارات:
- `/` الرئيسية · `/surah/1` فهرس السور · `/ayah/{سورة}/{آية}` صفحة الآية
- كل صفحة آية فيها **السابق / التالي** فتقرأ المصحف بالترتيب من الفاتحة إلى الناس

بلا تبعيات خارجية — مكتبة بايثون القياسية وحدها (3.11+).

## ما يُنتجه ٢:٢٥٥ اليوم

| العنصر | العدد | الطريقة |
|---|---|---|
| التفسير | ٢ | مفتاح مشترك |
| أحاديث باقتباس لفظي | ١٢ | مطابقة دقيقة بعد التطبيع |
| أحاديث بالتسمية | ١١ | «آية الكرسي» — تسمية مُقرَّرة مُسنَدة |
| أحكام العلماء | ٠ | الدرر السنية محجوبة في هذه البيئة |

## طرق الربط

لا يُنشأ رابط بلا حجّة يستطيع القارئ فحصها بنفسه. أربع طرق فقط،
مفروضة بقيد `CHECK` في المخطط:

| الطريقة | الحجّة |
|---|---|
| `shared_key` | التفسير مبوَّب على الآية أصلًا — مفتاح ٢:٢٥٥ |
| `quotation` | الحديث يقتبس لفظ الآية نصًّا (٦ كلمات متتالية فأكثر) |
| `naming` | الحديث يسمّي الآية باسمها المشتهر دون اقتباس لفظها |
| `manual` | ربط مُقرَّر يدويًا يحمل إسناده إلى موضع مطبوع |

**لا مطابقة تقريبية ولا تشابه دلالي.** رابط بلا حجّة قابلة للفحص
معلومةٌ بلا مصدر.

### اللفظ المشترك بين آيتين

«ٱللَّهُ لَآ إِلَٰهَ إِلَّا هُوَ ٱلۡحَيُّ ٱلۡقَيُّومُ» يفتتح ٢:٢٥٥ و٣:٢ معًا.
الحديث الذي يقتبسه قد يقصد أيًّا منهما. النظام يكتشف ذلك بمقارنة اللفظ
بالمصحف كاملًا، ويَسِم الرابط `ambiguous` مع ذكر الموضع الآخر، ويؤخّره
في الترتيب — **ولا يرجّح**. من ٢٣ رابطًا في ٢:٢٥٥، ١١ ملتبس مع ٣:٢
وقد صُرِّح بذلك في كل بطاقة.

## المخطط

```
source   المصادر وأرقام تثبيتها — لا يدخل شيء بلا مصدر مسجَّل
unit     وحدة نص: آية | تفسير | حديث   (text_ar حرفي · text_norm للمطابقة)
link     رابط مطبوع: from → to · method · evidence_ar · ambiguous
grading  حكم واحد: محدِّث + كتاب + موضع + درجة
```

`unit` **لا يحمل عمود `grade`** — القاعدة الحمراء الأولى مفروضة بالمخطط
لا بالاتفاق. اختلاف الأحكام يُمثَّل بصفوف متعددة، وتُعرض كلها مع تنبيه
«مختلَف فيه».

## المصادر ونقاط تثبيتها

| المجال | المصدر | التثبيت |
|---|---|---|
| القرآن (رسم إملائي) | fawazahmed0/quran-api | `6be8e17f` |
| التفسير | spa5k/tafsir_api | `05d5ba76` |
| الحديث | AhmedBaset/hadith-json | `v1.2.0` |
| الأحكام | الدرر السنية | الـ API الرسمي |

**الطبعة المعروضة**: الرسم الإملائي (`ara-quransimple`) لا العثماني — يُعرَض بثبات في الخطوط، ويطابق رسم متون الحديث فيرفع استرجاع الاقتباسات (آية الوضوء ٥:٦ ارتفعت من ٦ إلى ١٧ حديثًا). التطبيع يزيل الفروق فلا يتأثر الربط.

لا شيء مثبَّت على `main` متحرّك. الجلب يمرّ بكاش محلي على القرص
(`.cache/`) فلا يُضرب المصدر في كل طلب.

## الدرر السنية

المصدر الوحيد للأحكام، ومحجوب على مستوى الشبكة في بيئة التشغيل الحالية.
العميل مكتوب ومختبَر، وعند تعذّر الوصول يرفع `SourceUnavailable`:
لا يُرجع فراغًا صامتًا ولا يُختلق حكم. الواجهة تقول صراحةً:

> لم تُجلب أحكام العلماء على هذا الحديث من الدرر السنية.
> هذا نقصٌ في البيانات لا حكمٌ بعدم وجودها — ولن يُملأ بغير مصدر.

لتشغيلها: افتح `dorar.net` في سياسة الشبكة ثم `python3 -m turath.ingest 2:255`.

## الاختبارات

`tests/test_red_lines.py` — ١٨ اختبارًا تحرس القواعد الحمراء نفسها لا
الوظائف فقط: غياب عمود الدرجة، ظهور «مختلَف فيه» عند الاختلاف، رفض
المخطط لطريقة ربط غير مُعلنة، بقاء النص الأصلي بالتشكيل، وألا يظهر
المطبَّع في العرض. تعمل كلها بلا شبكة.

## التالي

- فتح الوصول إلى الدرر ثم إثبات عمود الأحكام كاملًا
- التوسّع أفقيًا إلى آيات أخرى بعد ثبات الرأسي
- أسباب النزول: البحث عن مصدر مهيكل — لا يُبنى بلا مصدر
- الفقه والسيرة: مؤجَّلان عمدًا حتى يوجد مصدر بجودة كافية

## النشر على GitHub Pages

```
python3 -m turath.build_static --out docs   # يبني موقعًا ثابتًا
```

يولّد HTML خالصًا بلا خادم: الرئيسية، فهرس السور، وصفحات آيات مبنيّة (الفاتحة كاملة، المعوّذات، آية الكرسي، آية الوضوء). الروابط مسطّحة نسبية فتعمل تحت مسار المشروع وعند فتح الملفات محليًا.

الدفع إلى `main` يُشغّل `.github/workflows/pages.yml` فيبني الموقع وينشره. توسيع التغطية: عدّل `FULL_SURAHS` و`EXTRA_AYAT` في `turath/build_static.py`.

> إن لم يظهر الموقع بعد أول دفع، افتح **Settings → Pages** وتأكّد أن المصدر **GitHub Actions**.
